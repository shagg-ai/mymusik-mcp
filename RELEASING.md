# Publish MyMusik MCP 0.1.0

Run these steps from the standalone release repository. Use an account with publishing access to the shagg-ai GitHub repository and the mymusik-mcp PyPI project. The connector and plugin code use the MIT license.

1. **Prepare the repository.** Publish this folder as `shagg-ai/mymusik-mcp` on GitHub. Include the hidden marketplace and plugin manifests. The Python package and Claude plugin use the bridge in `plugins/mymusik/mymusik_mcp`. Codex runs the wheel built from that directory. When preparing later versions from demo_cmake, refresh `mcp_stdio.py` there from `deps/Framework/Library/RestApiServer/tools/mcp_stdio.py` and rerun its connector tests.
2. **Verify the Python artifacts.** Reuse the verified wheel and source archive in `dist`. To rebuild in a clean checkout, run `python -m pip install build twine`, then `python -m build` and `python -m twine check --strict dist/*`. Install the wheel in a fresh environment and complete the pairing walkthrough before publishing. Keep the package version, plugin versions and registry package version aligned.
3. **Publish to PyPI.** From an authenticated publisher environment, run `python -m twine upload dist/mymusik_mcp-0.1.0-py3-none-any.whl dist/mymusik_mcp-0.1.0.tar.gz`. Check that `python -m pip install mymusik-mcp==0.1.0` works in a new environment. Tag the verified GitHub revision `v0.1.0` and attach the tested distributions to its release.
4. **Publish the registry entry.** The package description on PyPI must contain the README marker matching `io.github.shagg-ai/mymusik-mcp`. In a GitHub Actions job in `shagg-ai/mymusik-mcp`, grant `contents: read` and `id-token: write`, check out the release tag, install the official MCP publisher, run `mcp-publisher login github-oidc`, and run `mcp-publisher publish` beside `server.json`. Confirm the registry shows version 0.1.0 and the PyPI package with stdio transport. [Registry publishing with GitHub Actions](https://modelcontextprotocol.io/registry/github-actions)
5. **Submit to Claude.** Run `claude plugin validate ./plugins/mymusik`. In the developer portal, select **Submit new → Plugin bundle**, choose `shagg-ai/mymusik-mcp`, enter `plugins/mymusik` as the plugin path, and select `v0.1.0`. Validate, complete the data handling questions using the plugin README, and submit for review. [Claude developer portal](https://claude.ai/directory/manage)
6. **Distribute to Codex.** Once the GitHub repo is available and the wheel is installed on PATH, users run `codex plugin marketplace add shagg-ai/mymusik-mcp` followed by `codex plugin add mymusik@mymusik-plugins`. Pair and open a fresh local session. OpenAI's official desktop directory has a separate approved-partner process. [OpenAI desktop submission guide](https://developers.openai.com/plugins/deploy/desktop-only)
